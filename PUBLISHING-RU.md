# Как опубликовать проект на GitHub

**Публикуйте только содержимое этой папки**, а не папку установки игры и не архивы дампов/логов. Создание репозитория делает его доступным другим пользователям; не загружайте личные файлы.

## Через сайт GitHub (без команд Git)

1. Войдите в свой аккаунт на [github.com/new](https://github.com/new).
2. Имя репозитория: `ZeroParades-MelonLoader-Unity6-Fix`. Описание: `Experimental MelonLoader / Il2CppInterop Unity 6000.3.15 startup crash workaround for Zero Parades`.
3. Выберите **Public**. Не включайте автоматическое создание README, `.gitignore` и лицензии: они уже в нашем проекте.
4. Нажмите **Create repository**.
5. На странице пустого репозитория выберите **uploading an existing file** (или **Add file → Upload files**).
6. **Распакуйте** ZIP и перетащите на страницу все файлы из папки `ZeroParades-MelonLoader-Unity6-Fix` (не сам ZIP и не папку целиком, если не хотите получить лишний уровень вложенности). В корне должны оказаться `README.md`, `Install.ps1`, `Restore.ps1`, `GUIDE-RU.md` и остальные файлы.
7. Внизу в поле сообщения напишите `Initial guide and experimental workaround`, нажмите **Commit changes**.
8. Откройте страницу репозитория: GitHub автоматически отобразит англоязычный `README.md`. В нём есть ссылка на инструкцию по-русски.

После публикации можно поделиться ссылкой в комментариях к [моду на Nexus](https://www.nexusmods.com/zeroparadesfordeadspies/mods/14) и в [MelonLoader issue #1159](https://github.com/LavaGang/MelonLoader/issues/1159). Лучше сначала проверить, нет ли уже идентичного решения, и описывать это как **workaround, tested on one setup**, а не как официальный патч.

## Что лучше проверить до публикации

- В папке **нет** `.dmp`, `Latest.log`, `GameAssembly.dll`, `ZeroParades.exe`, `install-record.json`, Steam ID, паролей и токенов.
- Вы согласны указать исходные лицензии и авторство апстрим-разработчиков.
- Ссылка на Nexus ведёт к **чужому** моду; проект не заявляет авторства этого мода.
- **Объединённый установщик ещё не проверялся от начала до конца на отдельной Windows-машине.** Его составляющие были проверены в процессе отладки, поэтому проект помечен как экспериментальный. Если есть возможность, сначала протестируйте его в чистой папке с корректным MelonLoader.

После публикации название и тексты легко отредактировать прямо на GitHub.
