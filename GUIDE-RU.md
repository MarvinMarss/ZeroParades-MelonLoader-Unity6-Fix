# Zero Parades: как исправить вылет MelonLoader на Unity 6000.3

[English README](README.md) · [Разбор ошибок](TROUBLESHOOTING.md) · [Технический отчёт для разработчиков](UPSTREAM-REPORT.md)

**Кому подойдёт:** игра *ZERO PARADES: For Dead Spies* запускается без MelonLoader, но **вылетает с загрузчиком, даже когда папка `Mods` пустая**.

Мы проверили обход на Windows 11 x64, Zero Parades (Unity **6000.3.15f1**), MelonLoader **0.7.4-ci.2630** и библиотеке Il2CppInterop **1.5.1-ci.845**. В результате игра открыла главное меню, корректно закрылась, а мод [Force Crits Any Time](https://www.nexusmods.com/zeroparadesfordeadspies/mods/14) работал.

**Важно:** это экспериментальное решение, проверенное на **одной** установке. Оно отключает один внутренний перехват Il2CppInterop, поэтому другие моды могут перестать работать. Не устанавливайте его бездумно в другие игры или новые сборки MelonLoader.

## В чём была проблема

Сначала загрузчик не мог скачать или обработать зависимости, но после устранения этих ошибок игра всё равно вылетала с пустой папкой `Mods`. В журнале Windows возникало исключение **`0xc0000005`**, сбойный модуль **`GameAssembly.dll`**, смещение **`0x66eb4b`**. Дамп показал чтение недопустимого указателя. После применения исправления `Class_GetFieldDefaultValue_Hook` игра по-прежнему вылетала. Только дополнительное отключение перехвата `MetadataCache_GetTypeInfoFromTypeDefinitionIndex_Hook` позволило запустить игру и использовать выбранный мод.

Это доказывает эффективность **обхода в нашей конфигурации**, но не раскрывает окончательно первопричину неверного адреса или указателя.

## Установка с нуля

1. Установите MelonLoader, запустите Zero Parades хотя бы один раз, чтобы он сгенерировал библиотеки (`MelonLoader/Il2CppAssemblies/Il2Cppmscorlib.dll`). Если он вылетит после генерации — это ожидаемо при данной проблеме.
2. Установите Git и **.NET SDK 8**, если их нет:

   ```powershell
   winget install --id Git.Git -e
   winget install --id Microsoft.DotNet.SDK.8 -e
   ```

3. Закройте игру, сохраните резервную копию сохранений. Скачайте этот репозиторий как ZIP (на GitHub кнопка **Code → Download ZIP**) и **распакуйте**.
4. Откройте распакованную папку в Проводнике, щёлкните по адресной строке, наберите `powershell` и нажмите Enter.
5. Выполните:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
   ```

   Если игра лежит не в стандартной папке Steam:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -GameDir 'D:\SteamLibrary\steamapps\common\Zero Parades'
   ```

Скрипт скачает **исходники** Il2CppInterop с GitHub, выберет точную версию, добавит два изменения, соберёт DLL, **сделает резервную копию** исходной библиотеки и установит новую. **Готовые DLL, файлы игры и сам мод в этот репозиторий не включены.** Перед запуском можно самостоятельно прочитать `Install.ps1`.

## Проверка

Сначала запустите игру с **пустой папкой `Mods`**. Если она доходит до меню, закройте её, верните **только один мод** и попробуйте снова. Для указанного выше мода тест прошёл успешно. Это не гарантирует работу всех остальных модов: мы отключили потенциально необходимый им перехват.

Если ранее для отключения загрузчика вы переименовали `version.dll` в `version.dll.disabled`, верните исходное имя.

## Откат

Закройте игру и в **той же папке**, где запускали установщик, выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Restore.ps1
```

Он вернёт исходную `Il2CppInterop.Runtime.dll` из папки `backups/`. **Не удаляйте `backups/`**, пока не убедитесь, что всё работает. Откат касается только DLL внутри MelonLoader, а не файлов игры.

## Честные ограничения

- Это не универсальное исправление Unity 6 и не официальный патч загрузчика.
- Новый объединённый `Install.ps1` **не проверялся целиком** на отдельном компьютере; его части проверялись последовательно на работающей установке.
- Если вылетает уже **сама игра без загрузчика**, причина другая.
- Если MelonLoader показывает `0 Mods loaded`, но игра падает до меню, это **не доказывает** именно нашу ошибку: сравните сбойный модуль, смещение и версии.
- Не выкладывайте публично `.dmp`, Steam ID, полные личные пути и сохранения.

Дополнительные подробности и первоначальные ошибки приведены в [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
